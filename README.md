# Streamlit Visual Analytics Lab

This project is a web application developed using **Python and Streamlit** as part of a Visual Analytics laboratory exercise.

## Features

- Data visualization using Streamlit, Matplotlib, Seaborn and Plotly.
- Interactive maps and charts.
- User input widgets, including buttons, sliders and checkboxes.
- CSV file uploading and camera input.
- Caching to improve performance.
- Session State management.
- Multipage application structure.

## Technologies Used

- Python
- Streamlit
- Pandas & NumPy
- Matplotlib & Seaborn
- Plotly

## Project Structure

- `u232180.py` - Main application and data visualizations.
- `pages/page_1.py` - Interactive widgets and user inputs.
- `pages/page_2.py` - Caching and callbacks.
- `pages/page_3.py` - Session State management.

## How to Run

1. Install the required Python libraries:

   `pip install streamlit numpy pandas seaborn matplotlib "plotly<7" scipy`

2. Run the application:

   `python -m streamlit run u232180.py`

3. Open the application in your browser at `http://localhost:8501`.

## About

Developed as part of the Visual Analytics course at **Universitat Pompeu Fabra (UPF)** to explore interactive data visualization and web application development with Python.
